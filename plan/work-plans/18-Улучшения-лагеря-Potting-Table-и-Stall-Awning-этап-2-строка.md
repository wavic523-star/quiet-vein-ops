### Улучшения лагеря: Potting Table и Stall Awning (этап 2, строка «Улучшения лагеря за самородки: 2», 3 ч)

- **Источник:** таблица этапа 2; выбор владельца 18 ноября в чате «Сюжет» (О-53; MAT-049, M-0131); «Не делаем до запуска» — исключение для 2–3 улучшений. Rain Barrel — решение владельца 1 декабря, в блок не входит.
- **Статус:** проверен одним игроком в Studio 18 ноября, 23:56 («Разработка», место сохранено, версия 76); показ двум клиентам не проверялся (см. «Проверку»); подтверждён владельцем 18 ноября, 22:45.
- **Ограничения:** только за самородки, за Robux ничего. Формат данных (ответ «Сюжету» на З-2): `Camp.Upgrades = { PottingTable = 1, StallAwning = 1..3 }`, ключ — Id улучшения строкой, значение — уровень; нет ключа — не куплено (поле уже в v2). Бонусы к руде складываются и применяются один раз к сумме руды: питомец до 15 % + навес до 15 % (+ бонус за друга до 30 %, своим блоком); урожай без бонусов. Навес не связан с табличкой «×2».
- **Допущение (предложено):** показ другим (З-5, 0,5 ч внутри 3 ч) — клиентский: хозяин видит свой предмет всегда; игрок без своего видит предмет одного владельца на сервере (первого по времени входа) с подписью «{name}'s …», без уровня, навес как уровень 1. Если показ выйдет дороже 0,5 ч — навес к запуску одним уровнем (по слову «Сюжета»), сообщить «Плану».
- **Сцена** (qv-scene-build). Бюджет: до 12 частей в шаблонах `ReplicatedStorage.CampUpgrades` (их ставит клиент), света 0, украшений 0. Цвета — предложено до слоя оформления «Сюжета».

- **Задачи:**
  1. `GameConfig.CampUpgrades = { PottingTable = { Prices = { 1500 } }, StallAwning = { Prices = { 1500, 4000, 10000 }, OreBonus = { 0.05, 0.10, 0.15 } } }`; `Strings.Camp` — имена и подписи из MAT-049, подпись чужого «%s's %s». `ServerScriptService.CampUpgrades`: `Buy(player, upgradeId: string): string` — коды `bought`, `max`, `not_enough`, `no_upgrade`, `too_far`, `cooldown`; `Level(player, upgradeId): number`; атрибуты игрока `Upgrade_<Id>`. Проверка через служебный хук: покупка трёх уровней навеса списывает 1 500, 4 000, 10 000, четвёртая → max; не хватает → not\_enough без списания; неизвестный Id и число вместо строки → no\_upgrade.
  2. `ServerScriptService.SaleBonus`: `ForOre(player): number` = бонус питомца + бонус навеса; `MerchantServer` берёт его вместо `PetState.Bonus`. Проверка: 10 Copper (30) — без всего +30; навес 3 +35; навес 3 и питомец стадии 3 +39 (округление с суммы, как сейчас); урожай без бонуса.
  3. Potting Table: `GardenServer` действие `pot_all` — собрать со всех спелых клумб (с удвоением по виду) и посадить ту же культуру, пока хватает самородков на семя; только с купленным столом и у стола; один тост с итогом. Проверка: 3 спелые и 1 растущая — собрано 3, растущая не тронута; самородков на 2 семени — посажено 2, третья пуста и названа в тосте; без стола → отказ.
  4. `StarterPlayer.StarterPlayerScripts.CampUpgradesClient`: кнопки покупки у стола и у навеса (цена, что даёт, уровень); показ предмета из шаблона по допущению выше (сервер отдаёт атрибуты `Upgrade_<Id>` всех игроков, клиент выбирает, что ставить). Проверка: два клиента в Studio (Start Server, 2 игрока) — у владельца навес своего уровня, у второго — уровень 1 с подписью владельца; владелец вышел — предмет исчезает или переходит к следующему; телефон 667×375.
  5. Сцена по таблице, по qv-scene-build; перезаход с Mock — уровни на месте; снимки стола и трёх уровней навеса в галерею; `save_place`.
- **Что может подвести (фокус ревью):**
  1. Покупка дважды при двух быстрых нажатиях — проверка в задаче 1 (два вызова подряд → bought, cooldown).
  2. Potting Table сажает в минус самородков — проверка в задаче 3.
  3. Подпись чужого предмета показывает DisplayName игрока — имя из Roblox, без свободного ввода; длинное имя обрезается до 20 знаков, как в «Сообщении серверу» — проверка в задаче 4.
  4. Кнопка навеса перекрывает кнопки продажи Flint — проверка в задаче 4 на телефоне.
  5. Сумма бонусов считается дважды (питомец в старом и новом коде) — проверка в задаче 2.
